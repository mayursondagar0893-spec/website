Opening the page

  • Best way (Android and iPhone): open the web link you were given. On Android use Chrome. On iPhone use Safari.
  • iPhone: tapping the HTML file in WhatsApp, Mail or Files only shows a preview, and the buttons will not work. Always use the web link.
  • Add an icon: on iPhone, in Safari tap Share (the square with an arrow) → "Add to Home Screen" → Add. The icon shows your photo and the name "Physio Hub". On Android, in Chrome tap ⋮ → "Add to Home screen".
  • Always open it the same way, for example always from the Home Screen icon. Your data is saved inside that browser on that phone. On iPhone, data entered from the Home Screen icon may be kept separately from data entered in a normal Safari tab, so do not switch between the two.
  • PIN: each time the page opens, type the 6-digit PIN you were given and tap Unlock.
  • First-day test (important): add one test patient, close the page fully (swipe it away from recent apps), open it again the same way and check the test patient is still there. Then delete the test patient.
  • iPhone backups: tap "Download backup file". A share menu opens: choose "Save to Files" (or send it to yourself on WhatsApp). Safari can clear saved website data if a page is not opened for many days, so open the page regularly and keep weekly backups.
  • Opening as a file (Android only): you can also save the file on an Android phone and open it in Chrome. Some phones give a file a new address each time it is opened; then saved data will not reappear. If that happens, use the web link instead.
  • If you used an older version at the same address in the same browser, everything is carried over automatically. Old follow-up dates become appointments and old exercise plans become exercise programmes with the typical starting dose filled in (check and adjust it). If the older version was at a different address (for example as a file), take a backup there and restore it here (Settings → Backup and export).

Tabs and search

  • Tabs, in order: Today, Appointments, Patients, Exercises, Billing, Clinic Visits, Doctors, Content Studio, Prompt Library, Contact Card, Settings, How to Use. Swipe the tab bar left and right to see all.
  • To change the order or hide tabs you do not use, go to Settings → Tabs. Settings and How to Use cannot be hidden.
  • Tap 🔍 at the top to search everything: patients, mobile numbers, appointments, invoices, receipts, income and expense, doctors, letters, session and private notes, notebook, content ideas, exercises and this help. Type at least 2 letters and tap a result to open it.

Today

  • Shows today's appointments, your notebook, pending payments and patients not seen for 30 days or more.
  • Buttons at the top: Book appointment, Add patient, Tomorrow's reminders and Fee receipt.
  • My notebook: tap "Add note" for anything not about a patient (ideas, to-dos, purchases). Tick "Pin to top" for important notes. "View all" shows every note with a search box.
  • If you have not taken a backup for 7 days, a yellow message appears. Tap "Download backup now".

Appointments

  1. Tap "Book appointment". Choose the patient, date, time, duration and location. Tap "Save appointment".
  2. Before saving, the page checks: another booking at the same time, less than your travel gap around a home visit, a closed day (Tuesday by default), a leave date, or a time outside working hours. If there is a problem, you will see it. You can still tap "Save anyway".
  3. After saving, tap "Send confirmation on WhatsApp" and "Add to Google Calendar". In Google Calendar, tap Save.
  4. Use Day or Week view and the ◀ ▶ arrows. In Week view, tap a day to open it.
  5. Type a patient's name or mobile in the search box to see all their upcoming and past appointments.
  6. On each appointment: Done marks the session done (sessions +1, package used, last visit updated) and lets you add a quick session note. WhatsApp sends the confirmation. Reschedule / edit changes the time and offers a WhatsApp message with the new time. No-show and Cancel change the status (Cancel asks first). Maps opens the address for home visits.
  7. "Undo done" reverses a session marked Done by mistake.
  8. Every evening, tap "Tomorrow's reminders" and send each reminder on WhatsApp with one tap.

If you reschedule an appointment that you already added to Google Calendar, delete the old event in Google Calendar yourself. This page can add events but cannot change or delete them.

Patients

  1. Tap "Add patient". Fill name, mobile, age, gender, address, ID type and only the last 4 characters of the ID. For a patient under 18, the parent / guardian name is required and consent must come from the parent / guardian.
  2. Choose "How did they find you?" and, if a doctor referred them, select the doctor (add doctors in the Doctors tab first).
  3. Select therapies, fee per session and usual visit type.
  4. Packages: type a name, number of sessions and amount, then tap "Add package". Sessions are counted against the package first. Balance = package amounts + (sessions outside packages × fee) − fees paid.
  5. Tick the consent box. You cannot save without it.
  6. Each patient card has four rows of buttons. Visit: Book, +1 session, Notes, Consent, Maps. Care: History, Exercise programme, Doctor update. WhatsApp: Appointment, Exercise programme, Payment reminder (only if balance is due), Check-in (only if not seen for 30 days) and Privacy note. Money: Invoice, Fee receipt, Edit, Delete.
  7. Send the "Privacy note" to every new patient. It explains why you keep their details and that they can ask you to correct or delete them.
  8. Deleting a patient also deletes their appointments, session and private notes, consent forms and doctor letters. Income entries, receipts and invoices stay for your accounts.

Patient history

  • Tap the patient's name (or "History") to see everything in one place: joined date, how they came, referring doctor, sessions done, package sessions left, upcoming appointments, balance or advance, total paid and billed, cancelled and no-show counts.
  • Below that: upcoming appointments, all receipts and invoices, session notes with the pain chart, private notes, exercise programme, consent forms, doctor letters and a full timeline by date.
  • Use the search box in "Session notes" to find a word in session notes and private notes.
  • Private notes are for things like "prefers evening slots". They are never sent to anyone.

Session notes

  1. Tap "Notes" on a patient, then "Add note". Or mark an appointment Done and the note form opens.
  2. Move the slider for the pain score (0 = no pain, 10 = worst), tick the treatment given and write progress.
  3. With 2 or more pain scores, a pain-trend chart appears.

Exercise programme (home exercises)

  1. Tap "Exercise programme" on a patient. Search an exercise and tap "Add". Add as many as needed.
  2. Each added exercise is filled with its typical starting dose (or your own saved typical dose). Change Sets, Reps, Hold, Frequency and Duration as needed for this patient, and add an optional note. Use ↑ ↓ to change the order.
  3. Quick fill: type values in the Quick fill boxes and tap "Fill empty boxes" to fill any boxes you cleared.
  4. Fill Pain allowed, Stop if, Next progression, Review date and General instructions.
  5. Tap "Save programme". "Save and print / PDF" makes the full programme with pictures, ready to save as PDF. "Save and WhatsApp text" sends it as a message.
  6. To send one exercise, tap "Share animation (GIF)" for a moving picture with this patient's dose, or "Share picture (JPEG)" for a still picture. "Download GIF" and "Download JPEG" save them.
  7. From the Exercises tab you can also choose a patient and tap "Add to plan"; then set the dosage in Exercise programme.

Clinic Visits

  • Use this for your work at other doctors' clinics, where the clinic keeps its own patient register.
  • Add clinic (once): clinic name, doctor, area, clinic WhatsApp number, payment cycle and whether the clinic deducts TDS. Then choose how the clinic pays you:
    • Fixed amount per service: type your amount for each service.
    • % of the service fee: type your share % and the fee for each service; your share is worked out.
    • Patients pay me directly: no service amounts are needed.
  • Services: four are filled in for you (Exercise only, Machine (IFT/TENS/Ultrasound), Exercise + machine, Dry needling / cupping / taping). Untick a service the clinic does not offer, change names or amounts, tap ✕ to remove one, or tap "+ Add service" to add your own. Changing amounts later does not change days already saved.
  • + Clinic day: choose the date and clinic, then pick:
    • Service-wise: tap − and + for the patients in each service. The total is worked out and you can change it. Use "Other (one-off)" for anything unusual: a description, number of patients and total amount.
    • Quick total: just type the day's total amount (and the number of patients if you know it).
    The form remembers your last choice for each clinic. Patient initials are optional; do not enter full names. If some patients paid you directly, enter that amount and mode; it goes straight to Billing as income.
  • Each clinic card shows days worked, earned, received and pending. When a clinic is past its usual payment cycle, it shows "Payment overdue". Clinics with pending amounts also appear on Today.
  • Payment received: enter the amount received and any TDS the clinic deducted. It reduces the clinic's pending amount (oldest days first) and is added to Billing as income of the amount received plus TDS.
  • Statement: choose a month to see each day's services or day total, and a month summary per service. Send it to the clinic on WhatsApp to tally with their register.
  • Entries made from Clinic Visits show in Billing under "Visiting clinic". To change or delete them, use Clinic Visits, not Billing.
  • To stop using a clinic, open Edit and untick "Active". A clinic with entries cannot be deleted.
  • Backup and Google Sheet: all clinic data is included in the backup file and in "Send data to Sheet". The Google Sheet shows readable tabs: Clinics, ClinicRates, ClinicDays and ClinicPayments.

Doctors and doctor updates

  1. In the Doctors tab, tap "Add doctor": name, speciality, hospital, mobile and email. "Dr." is added automatically.
  2. Link a doctor to a patient in the patient form. The Doctors tab shows how many patients are linked and letters sent for each doctor.
  3. To write an update, tap "Doctor update" on the patient. Choose the doctor (or "Add new doctor"). Dates, sessions, initial presentation, treatment and progress are filled from your records. Check and edit every section, and write the functional status and recommendations yourself.
  4. Tick that the patient agreed to share the update with this doctor. You cannot save without it.
  5. Then: "Print / Save PDF", "WhatsApp to doctor" (sends the text) or "Email". Email opens with the letter text; to attach the PDF, save it first and attach it in your email app.

Consent forms (dry needling, cupping and more)

  1. Tap "Consent" on a patient, then "New consent form".
  2. Tick the procedures. The consent statement updates to show the matching risks.
  3. Go through the safety check with the patient. If any item is ticked, a caution appears. Consider medical clearance from their doctor and adjust or avoid the procedure.
  4. The patient (or parent / guardian) signs with a finger in the box. Tick that you explained the procedure and tap "Save consent".
  5. Tap "View / print PDF" to print or save it as PDF.

The consent wording is a general draft. Have it reviewed once by a senior physiotherapist or your professional association.

Invoices and fee receipts

  • Invoice asks for payment and can show your bank details and UPI QR code. Numbers look like INV/2026-27/001.
  • Fee receipt confirms payment received. It is added to income and to the patient's fees paid. Numbers look like RN/2026-27/001.
  • Both have an optional "Remarks" line that is printed on the document.
  • On an invoice, tap "Mark paid (make receipt)" when the patient pays. The receipt is created and the invoice shows Paid.
  • Share on WhatsApp (JPEG): opens your phone's share menu with the invoice or receipt picture attached. Choose WhatsApp, then the patient. If your phone does not show the share menu, the picture is downloaded and WhatsApp opens with the text; attach the picture from your downloads.
  • "Download JPEG" saves the picture. "Print / Save PDF" makes a PDF. "Send as text" sends the details as a message.
  • These documents do not use GST terms such as "Tax Invoice". Check your GST position with your Chartered Accountant.

Billing

  1. Tap "Add income" or "Add expense", pick category and payment mode, enter amount and save.
  2. If you edit or delete a receipt entry, the linked patient's fees paid is corrected automatically, and a linked invoice shows Unpaid again. A receipt's date can only be changed within the same financial year.
  3. Choose the financial year and month to see totals. Use the search box above the invoice list to find an invoice by number or name.
  4. "Monthly report" shows sessions done, appointments, no-shows, new patients, income, expense, where new patients came from, doctor letters sent and posts published. Tap "Print / Save PDF". The report has no patient names.
  5. "Export this FY to Excel (CSV)" downloads a file that opens in Excel or Google Sheets.

The tax note in the FY summary is only for general information. Please confirm your tax position with your Chartered Accountant.

Content Studio

  1. Search a topic or choose a category and format (Reel, Flyer, Carousel).
  2. Tap "Open script & prompts" on any idea. You will see your bio line, the script (or slides / flyer layout), on-screen captions and the post caption. Each has a Copy button.
  3. Under "AI prompts", tap ChatGPT / Gemini, Canva, CapCut, AI video or Claude, then tap "Copy prompt" and paste it in that app.
  4. Tap "Make flyer" to create a ready flyer with your photo and contact details. Edit the text, then tap "Download image".
  5. Tap "Schedule" to add the idea to your content calendar. Open "Content calendar" at the top to see planned posts, mark them posted or add a Google Calendar reminder. "Add custom post" adds your own idea.

Every prompt already includes ethics rules: no cure or guarantee claims, no patient before/after photos, safe technique only. For AI video, record your own talking parts yourself; do not let an AI create a fake video of you.

Emergency-awareness ideas (stroke signs, back and neck red flags, warning signs after surgery) end with "call 112 / 108 or go to the emergency department", not a booking message. Ideas such as facial palsy and falls advise seeing a doctor first. Please keep it that way when you edit.

Before posting, read every script once yourself and change any line that does not match how you work. For "Why I became a physiotherapist", use your own real story.

Exercises

  1. Search or choose a body area. Each card shows the typical starting dose.
  2. Tap any exercise to see its animation. Tap "Pause" to stop it at any point.
  3. You will see the typical starting dose table (sets, reps, hold, frequency, duration), why the exercise is used, benefits and when not to do it. These doses are general starting values; always adjust them after assessment.
  4. To use your own usual dose for an exercise, tap "Edit typical dose" and save. Your values are then used everywhere. "Use original typical dose" brings back the original.
  5. Share animation on WhatsApp makes a moving picture (GIF) with the exercise name and dose, and opens your phone's share menu with the GIF and the text. Choose WhatsApp. It takes a few seconds. "Download GIF" saves it; "Send as text" sends only the text.
  6. Choose a patient and tap "Add to plan" to add the exercise to their programme with the typical dose filled in.
  7. Body areas now also include Hand, Wrist & Elbow; Pelvic Floor; Vestibular (dizziness); Jaw (TMJ); and Paediatric (parent-guided play). Exercises that cannot be animated (fingers, eyes, jaw, pelvic floor) show a clear still picture instead, and "Share picture on WhatsApp" sends that picture.
  8. Many exercises now show How to do it steps. The steps are included when you send the exercise as text.
  9. Programme templates: tap "Open templates" at the top of this tab.
    • Built-in post-op templates: total knee replacement, ACL reconstruction and rotator cuff repair, phase by phase, with goals, precautions, when to move on, and exercises. Tap "Apply to patient", choose the patient, then "Replace programme" or "Add to programme". "Save a copy as my template" copies a phase into My templates so you can change it.
    • My templates: open a patient's Exercise programme, type a name in the Templates box and tap "Save as my template" (doses are saved too). Saving again with the same name updates that template. In "Open templates" you can apply, rename or delete your templates.
    • Inside a patient's Exercise programme you can also choose any template and tap "Add" or "Replace", then "Save programme".
  10. Built-in templates are general guidance. Always follow the operating surgeon's protocol where it differs, and adjust after your assessment.

Movements that cannot be seen clearly from the side (neck turning, ankle circles, breathing, hand, trunk rotation, shoulder rotation with band, clamshell, wrist stretches) are shown as close-up views from the front, from above or of the body part itself.

WhatsApp may turn a GIF into a short video when sending. It still plays on the patient's phone.

Google Sheet sync (one-time setup, about 10 minutes)

  1. Open Google Sheets on a computer and create a new blank sheet. Name it "Physio Hub Data".
  2. In that sheet, click Extensions → Apps Script.
  3. Delete any code you see. In this page, go to Settings and tap "Copy Apps Script code". Paste it in Apps Script and click Save.
  4. Click Deploy → New deployment → select type "Web app".
  5. Set "Execute as: Me" and "Who has access: Anyone". Click Deploy and allow the permissions Google asks for.
  6. Copy the "Web app URL" and paste it in Settings → Web app URL. Keep the Secret key exactly as shown (it is already inside the code you copied). Tap "Save sync settings".
  7. Tap "Send data to Sheet". Open your Google Sheet: you should see tabs such as Patients, Appointments, SessionNotes, Consents, Money, Invoices, ContentPlan, Doctors, DoctorLetters, PrivateNotes, Notebook, Clinics, ClinicRates, ClinicDays, ClinicPayments and MyTemplates.
  8. On a new phone, paste the same URL and key and tap "Load data from Sheet".

Already set up with an older version? Update the code once: in Settings tap "Copy Apps Script code". In the Google Sheet open Extensions → Apps Script, select all the old code, paste the new code and click Save. Then click Deploy → Manage deployments → the pencil (Edit) icon → Version: New version → Deploy. The Web app URL stays the same, so nothing changes on your phone. Without this update, sync and restore still work, but the clinic tabs are not shown in a readable form.

If you set up sync with an older version, copy the new Apps Script code again, paste it over the old code, and deploy a new version (Deploy → Manage deployments → Edit → New version). Signatures, your QR photo and your profile photo are not sent to Google Sheet; they stay in the backup file. Never share the Web app URL and key with anyone, because together they give access to patient data.

PIN lock and privacy

  • Each time the page opens, it asks for your 6-digit PIN. Type it and tap Unlock. Tap 🔒 at the top to lock it anytime.
  • After 5 wrong tries, wait 30 seconds before trying again.
  • The PIN is fixed inside this page and cannot be changed in Settings. To change it, ask the person who set up this tool for a new version.
  • Forgot the PIN? Ask the person who set up this tool. Your data is not lost; it stays saved on your phone.
  • The PIN hides the screen from others. It is not bank-level encryption, so keep your phone itself locked too.
  • Save only the last 4 characters of ID documents. Take patient consent before saving details, and the patient's agreement before sending updates to a doctor.
